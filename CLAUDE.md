# Spelregels

## Communicatie
- Antwoord in het Nederlands.
- Schrijf code-commentaar ook in het Nederlands.
- Vraag door wanneer je meer informatie nodig hebt.
- Meld het duidelijk als iets niet gelukt of niet getest is.
- Laat elke keer voordat je code toevoegt de code zien en vraag of het duidelijk / begrijpelijk genoeg is.
- Vraag toestemming om iets te runnen. 
- Vraag toestemming om veranderingen door te voeren in de code. 
- Sluit af met een korte samenvatting van wat je hebt gedaan en welke bestanden zijn gewijzigd.

## Werkwijze
- Werk alleen in de toegestane map (`C:\Werkmap\Claude\Claude_LVO_dashboard`). Als je erbuiten wilt werken, vraag dan eerst om toestemming.
- Leg bij grotere wijzigingen eerst kort je plan uit en wacht op akkoord.

## Code
- Programmeer altijd in Python.
- Schrijf boven elke regel code of stukje code dat bij elkaar hoort een korte uitleg (als commentaar, in het Nederlands).
- Gebruik duidelijke variabele namen zodat de code begrijpbaar blijft. 
- Zorg dat de code kort en bondig is en dat het duidelijk is voor mensen met niet zo veel progammeer kennis om te begrijpen. 
- Sla de gebruikte code altijd op in een los bestand, zodat de gebruiker die zelf kan bekijken en draaien.
